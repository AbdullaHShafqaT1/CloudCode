Build a small, fully working Python command-line application called Integer Summary. Use only the standard library. This is a command-line task, not a windowed application.

Required files: app_logic.py, app_gui.py, main.py, test_app.py, README.md, RunningGUIDE.txt. The name app_gui.py is retained as the pipeline's presentation-layer module: it formats CLI output only.

Exact callable contract in app_logic.py:
summarize(values) accepts a nonempty list or tuple of Python integers. Boolean values are not integers for this contract. Return a dict with exactly count, total, mean, minimum, maximum. count is the number of entries; total is their sum; mean is total/count; minimum and maximum are their extrema. Raise ValueError for an empty list/tuple. Raise TypeError for a non-list/tuple argument or any non-integer element, including bool, float, or str. Do not modify the input.

app_gui.py exports format_summary(result), returning JSON text for the dict. main.py accepts one or more positional integers, calls summarize, and prints exactly one JSON object followed by a newline. Example: python main.py 1 -2 3 yields count=3,total=2,mean=2/3,minimum=-2,maximum=3. Missing arguments and invalid integers must exit nonzero with a helpful error on stderr, without a traceback. Importing any module must not execute the CLI.

test_app.py must contain genuine unittest.TestCase tests for normal, negative, singleton, tuple, large-integer, empty, boolean, float, string and invalid-container cases. README.md and RunningGUIDE.txt must give the exact launch command, contract, errors and test command. No dependencies beyond the Python standard library.

Use the real read, write and terminal tools. Follow the workflow's phases, producing complete explicitly named files one at a time. Run the tests and repair your own errors. Independent acceptance checks are supplied by the caller and must not be modified. Do not launch a long-running process. Declare completion only after the actual application and tests work.
